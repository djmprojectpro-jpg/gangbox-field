The app lives at the **root** of this repo. Expo should not look in a subfolder.

## Connect Expo to this repo (once)

1. Sign in at [expo.dev](https://expo.dev) as **djmprojectpro-jpg**.
2. Create a project named **Gangbox Field** (slug `gangbox-field`) if you do not have one.
3. Project settings → **GitHub** → connect GitHub.
4. Select repository **djmprojectpro-jpg/gangbox-field**.
5. Root directory: leave empty / `.`
6. Trigger a **preview** build.

After that, `https://expo.dev/@djmprojectpro-jpg/gangbox-field` will exist instead of 404.

Install [Expo Go](https://expo.dev/go) on the phone. Open the project from Expo, or scan the QR Expo shows after the first build.

Sign in with the same shop email. Type the shop URL once; the phone remembers it.
